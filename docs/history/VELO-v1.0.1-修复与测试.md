# VELO 1.0.1 修复与测试

## 这次修正

- 码表连接独立于骑行服务。打开应用后连接已选择的设备，选定新设备立即连接；失败时每隔约 3 秒重试，结束骑行保持连接。
- 首页支持“展开地图／收起地图”，提供明确的加减缩放按钮。
- 底部横杠已实现拖动。按住面板顶部向下拖到收起档，向上拖到半展开或展开档；面板内容本身仍可滚动。
- 长按地图后显示橙色“选”标记，详情中的坐标与该标记一致。地图自动跟随和播放在手动操作时停止；普通数据刷新不会重新缩放地图。
- 双指操作结束后不再继续执行单指拖动，避免缩放松手时发生跳动。
- 设备页面动态更新连接状态。

## 安装

同一局域网下载，覆盖安装，无需先卸载：
http://192.168.45.24:8765/VELO-PhoneBridge-v0.2.apk?version=1.0.1

首次使用到“设备”选择一次已经在系统蓝牙中配对的码表。以后打开软件自动连接它。若系统尚未授予附近设备权限，需先授权。

## 验证范围

59 项 Android 集成检查通过；另外 23 项 GPS、服务、记录导出及诊断检查通过。最终安装包的局域网下载内容已与本地 APK 校验一致。

自动化测试会验证真实触摸长按、双指缩放、面板拖动、全屏切换，以及收藏、路线、地图坐标对齐和导航服务流程。自动连接服务的启动和重试状态可在模拟器验证；当前电脑只连接了 Android 模拟器，没有连接用户手机，无法用模拟器证明 TCL 手机与 ESP32 的实际蓝牙连接成功。实机蓝牙与户外定位仍需安装后确认。

免费地图、搜索和规划服务仍依赖网络，其覆盖与 Google 不同。本次修复不能据此宣称已经达到成熟商业地图软件的全部能力。
