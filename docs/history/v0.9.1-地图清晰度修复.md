# VELO v0.9.1：地图清晰度修复

上一版使用 256 像素的地图图片，并按手机屏幕密度放大。在高密度屏幕上，地图文字和线条会被放大约 2～3 倍，连续缩放时还可能进一步拉伸，因此看起来发糊。

本版改用 MapLibre + OpenFreeMap 矢量底图。道路、文字和图标按屏幕分辨率绘制，避免拉大低分辨率图片。地图风格会变化；选点、标签、路线、地图预演与诊断记录继续保留。

## 更新

覆盖安装 `VELO-PhoneBridge-v0.9.1.apk`，不需要卸载，也不需要为本次修复刷写码表。

局域网兼容下载地址：

http://192.168.45.24:8765/VELO-PhoneBridge-v0.2.apk?version=0.9.1

兼容文件名沿用旧版，实际内容为 0.9.1。首次加载新底图可能需要稍等；保持联网。

“设置 → 地图来源（高级）”现在提供清晰街道、简洁浅色、夜间三种风格。自定义来源改为 MapLibre 矢量样式 HTTPS 地址，不再使用旧版的图片瓦片地址。

## 验证与限制

已在模拟器同一坐标检查实际地图显示，并通过 26 项地图交互、标签、预演隔离及标记对齐检查。验证了渲染画布使用屏幕实际像素，原生标记与矢量地图投影在测试位置的误差小于 4 个屏幕像素。真实 TCL 手机效果仍需安装后确认。

地图渲染依赖 Android System WebView 的 WebGL 支持；如系统组件不支持，会显示提示。地图仍需要网络，不保证离线底图可用。周边设施覆盖、搜索与路线规划的已有局限仍存在。

底图请求会发送当前查看区域；标签仍在本机保存。地图预演继续明确标记为模拟，不发送模拟位置到码表。

MapLibre 5.10.0 的脚本和样式已随安装包内置，开源许可可在应用“关于 → 开源许可”查看；无需每次从脚本 CDN 下载渲染库。
