# VELO 自行车码表：第一版

当前固件已升级支持 v0.4 路线帧，使用方法见上级目录《路线版使用说明.md》。BOOT/GPIO0 或串口 `PAGE` 切换路线页与码表页。路线帧为 `M,序号,R或G,偏航标志,拐点方向,拐点米数,剩余米数,窗口宽米数,航向角,线段数量,x1,y1,x2,y2,...`，坐标限 0～127，最多 40 段；整帧验证通过才替换画面。R 为模拟回放、G 为 GPS。`MAPOFF` 取消路线帧，5 秒无更新不继续显示旧路线。

适配 Ideaspark ESP32-WROOM-32，集成 ST7789 135×240。Arduino 开发板选 ESP32 Dev Module，端口 COM8。

## 当前功能

大字号速度、公里里程、小时分钟骑行时间、直行/左右转/掉头/到达图标。启动默认 DEMO，全部为模拟数据；本版不读取 GPS，也不自动读取 Google 地图。屏幕使用英文以避免内置字体缺少中文字库。

手机接入方式：经典蓝牙串口，设备名 VELO-ESP32。配套安装包位于上级目录 VELO-PhoneBridge.apk；安装和权限步骤见上级目录《开始使用.md》。Google 地图通知转发需要用户在手机授予通知访问权限，兼容性需要真机验证。

## 验证屏幕和通信

已修复有效数据包被拒收的问题：解析结果应为 5 个字段（`%n` 不计入返回数量）。修正版已在 COM8 验证有效包接收、越界值和多余尾部拒收，并观察到手机蓝牙持续发送的有效数据。串口输入 `STATUS` 可查看 accepted/rejected 计数、fresh 数据新鲜状态、bt 蓝牙连接状态及 demo 模式。

串口监视器设 115200，行尾选“新行”。输入 LIVE 后进入等待真实数据状态。输入以下一行，可验证左转提示和数据接收（这是手动测试数据，不是真实骑行）：

```
D,23.5,1.25,600,L,120
```

依次表示 km/h、累计 km、骑行秒数、方向、到下一转弯的米数。方向 S 直行、L 左转、R 右转、U 掉头、A 到达、N 无导航数据。速度 -1 表示没有可靠定位，距离 -1 表示没有转弯距离。配套程序每秒发送一行；5 秒无更新则清除数据并显示 NO DATA。输入 DEMO 可恢复演示。串口和蓝牙使用相同协议。

## 屏幕引脚

MOSI 23、SCLK 18、CS 15、DC 2、RST 4、背光 32。请对照实际板子版本；屏幕亮起、方向和颜色仍需观察实物确认。

依赖 Adafruit ST7735 and ST7789 Library、Adafruit GFX Library（及自动安装依赖）；BluetoothSerial 来自 ESP32 开发板支持包。无需修改库里的引脚配置。

手机配套源码在 PhoneBridge 目录。通知文字随语言和地图版本变化，未识别的提示显示 NO TURN DATA。它是通知文字解析原型，不是 Google 官方导航接口；没有完整地图、道路图形和自动路线规划。下一步需要在 TCL 手机上验证安装、蓝牙、GPS 和实际地图通知。
