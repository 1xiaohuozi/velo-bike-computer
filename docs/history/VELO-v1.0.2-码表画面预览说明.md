# VELO 1.0.2：设备页码表预览

连接码表后，设备页自动显示按 135×240 屏幕布局绘制的预览，每秒更新。包含速度、路线、周边道路、转向提示和 GPS 状态，可在地图预览与数据预览之间切换。断线时自动收起，发送数据过期后不会沿用旧画面。

预览取自最近一次成功写入蓝牙连接的数据，不是码表屏幕截图，也不代表硬件已确认显示成功。手机预览切页不控制码表按键；当前版本不读取码表实际选中的页面，也不复现硬件字体和屏幕刷新过程。

首次连接和待机无需启动骑行。尚无导航数据时，预览显示等待或无转向数据，绝不预置虚构速度。
