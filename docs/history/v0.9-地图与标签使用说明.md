# VELO v0.9：周边地图、标签与路线预演

覆盖安装 `VELO-PhoneBridge-v0.9.apk`，无需卸载，也不需要为本次手机地图功能重刷码表。原有起终点、路线和设置会保留。

## 看周围有什么

首页现在显示 OpenStreetMap 在线街道底图，可以拖动、双指缩放、双击放大。点击“展开地图 · 标签 · 路线播放”，进入大地图。

地图显示当地数据中收录的道路、建筑、河流、公园、车站及部分设施、店铺名称。缩放级别不同，显示的内容也不同。它并不保证具有 Google 相同的商户覆盖，也没有营业时间、评价或商户详情页。底图自带的文字不是可点开的商户卡片。

“＋ / －”缩放，“全路线”查看当前路线或待规划起终点，“定位”返回手机当前位置。定位需要手机权限和有效位置。

## 在地图上选起点和目的地

1. 长按地图上的目标位置。
2. 选择“设为目的地”或“设为起点”。
3. 在地图下方点击“规划路线”。也可以使用右上角“搜索地点”选点。
4. 等路线显示后，确认是否符合预期；实际骑行仍从首页点击“开始骑行”连接码表。

改变地点后旧路线会隐藏，直到新路线规划成功。地图上不会用一条直线冒充规划路线。

## 添加自己的标签

长按地图 → 添加标签 → 输入名称 → 保存。

例如可以记录“补水点”“集合点”“想去的地方”。这些是你自己添加的标记，不代表软件已经核实该处设施。标签在手机本地保存，覆盖更新和重开应用后仍在；卸载应用会丢失本地数据。

点击标签圆点或文字，可设为目的地、设为起点、重命名或删除。大地图下方的“标签”按钮可以列出已保存标签。最多保存 100 个。

## 在地图上播放路线

先规划或导入路线，再点击大地图下方“播放路线”。橙色圆点沿路线移动，可暂停，也可拖动进度条查看某一段。蓝色圆点用于手机有效位置。

地图预演会明确显示“非实际位置”，只在手机地图上播放，不启动骑行服务，不改变码表上的实际导航数据。它也不会把预演轨迹写成真实骑行。需要实际导航时使用首页“开始骑行”。

## 网络与数据

- 地图使用免费公共底图，不需要配置付费 API 密钥；可用性和数据覆盖有限。
- 查看地图会向底图服务发送当前查看区域的瓦片请求，并使用本地 HTTP 缓存减少重复请求。
- 只请求正在查看的区域，不提供城市或整条路线的离线地图下载。不能保证断网后仍能看见所有地图细节；已下载的路线几何与在线底图是两回事。
- 标签本地保存，不会自动上传。规划和搜索仍使用已有的对应服务。
- 可在“设置 → 地图来源（高级）”切换兼容 HTTPS 地图地址及版权署名。

地图数据与署名：© OpenStreetMap contributors。底图使用规则：https://operations.osmfoundation.org/policies/tiles/ 。
