# VELO 1.0.4

界面统一为深绿主色、浅色背景和圆角卡片。新增原生点击水波纹、底部导航选中动画、页面淡入与轻微位移、地图面板入场，以及规划中的加载组件。未改换地图或导航数据服务。

## 清除当前路线

地图首页的“继续查看”下方，以及规划页，都有“清除当前路线／清除路线”。清除后移除当前路线、起点、终点、途经点和地图预演状态；不会删除收藏、已保存路线与骑行记录。已保存路线仍可从路线库重新打开。

如果正在骑行，确认后先结束并保存骑行记录，再清除当前路线；蓝牙连接保持。清除后重新打开应用，不会从旧 GPX 或路线缓存自动恢复。
