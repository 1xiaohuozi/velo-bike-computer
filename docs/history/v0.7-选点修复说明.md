# VELO v0.7：目的地选择修复

直接覆盖安装，无需卸载旧应用，也无需重新刷写码表。

1. 点击首页的“搜索目的地”。输入地点名称、地址，或 `纬度,经度`。
2. 点击“搜索地点”，点选下方结果，再点击“设为目的地”。
3. 返回首页后应看到“✓ 目的地：…”；预览会显示已选终点，并提示等待规划。
4. 点击起点，可定位或搜索选择。起终点都会保存，应用重开后仍保留。
5. 点击“规划自行车路线”。成功后预览显示道路路线和目的地名称，再点击“开始骑行”。

更换起点或目的地后，旧路线不会冒充新路线；需重新规划才能开始。正在进行的骑行仍跟随原路线，直至新路线规划成功。搜索或规划失败时会显示原因。

地点搜索采用免费 Photon / OpenStreetMap 公共接口，只在点击搜索时发出请求。有起点时，会将起点坐标用于附近结果排序。公共接口超时或无结果时，尝试手机系统地名服务，并在有结果时注明“备用系统搜索”。支持最多 10 个最近选中地点。搜索、起终点与路线缓存在本机。

搜索词和可选的起点坐标会发送到搜索服务；规划起终点会发送到 BRouter。免费公共服务的覆盖和可用性有限，不等同于 Google 地点搜索。手机预览目前仍是简化路线，没有街道底图；偏航仍需手动重新规划。

数据来源与接口说明：

- https://github.com/komoot/photon
- https://github.com/abrensch/brouter
