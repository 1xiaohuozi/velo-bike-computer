# VELO 1.0.3：明确选择路线地点

- 每个地点都可以明确设置为起点或终点，也可加入途经点；收藏添加顺序不决定路线顺序。
- 起点、途经点、终点按规划页顺序提交，不在后台重新选取默认地点。
- 新建路线清空上一条草稿的起终点与途经点，不删除收藏和已保存路线。
- 手动设置地点会取消旧定位请求。旧定位结果不能覆盖手动起点，定位完成也不再自动提交规划。
- 使用当前位置作为起点后，须核对地点，再点击规划按钮。
- 起终点显示坐标，途经点在地图上按顺序编号。把途经点改成起点或终点时移除重复的途经角色。
- 修改地点后必须重新规划，不能把旧路线直接当作新路线开始骑行。
